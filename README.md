# LINE Stamp Maker

Mobile-first PWA for creating LINE stamp assets on iPhone.

## Phase 1–2

- Next.js App Router + TypeScript + Tailwind CSS
- iPhone-first UI with Safe Area support
- PWA manifest and service worker
- IndexedDB (`idb`) with `projects`, `images`, and `settings` stores
- Project create/list/open/duplicate/delete
- Related image cleanup on project deletion

## Commands

```bash
npm install
npm run dev
npm run lint
npm run build
```
